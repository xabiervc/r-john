# R-John Writing Style Guide

## Core Principles
1. Character Voice Consistency - Each NPC has distinct speech patterns
2. Subtext Over Exposition - Show don't tell
3. Choices Must Have Weight - Genuine tradeoffs, no obvious best
4. Avoid Clichés - Challenge tropes
5. Earn Emotional Moments - Build toward payoff

## Character Voices
- Maria: Direct, efficient, professional
- Laura: Earnest, nervous, eager
- Emma: Hesitant, formal, respectful
- Jessica: Sharp, probing, concise
- Victoria: Calculating, elegant, commanding
- Ashley: Bold, playful, provocative
