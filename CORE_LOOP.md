# R-John: Core Loop Document

**Única fuente de verdad para bucle de juego**

## Bucle Principal
Chapter Start → Dialogue con NPC (2-4 choices) → Stats update → Chapter End → (Repeat ×7) → Final

## Stats del Jugador (3)
- Reputation (0-100, initial 50)
- Lust (0-100, initial 30)
- Risk (0-100, initial 30)

## Stats de Relación (40 total, 4 por NPC)
- Trust, Respect, Attraction, Loyalty

## Tipos de Decisiones
1. Stats (60%): Cambios inmediatos ±3-20
2. Relación (25%): Trust/Respect/Attraction/Loyalty changes
3. Consecuencia Retardada (10%): Trigger en capítulos futuros
4. Final (5%): Determina ending path

## 12 Finales
- Victory (2): Statesman, Power Broker
- Damaged (2): Cautious Politician, Private Life
- Strategic (2): Reinvention, Scandalized Exit
- Downfall (2): Disgraced, Destroyed
- Secret (4): Kingmaker, Redemption, Untouchable, Truth

## Timeline
- Playtime: 2.5-3.5 horas (primera vez)
- 100% completion: 10-15 horas (4-5 playthroughs)
