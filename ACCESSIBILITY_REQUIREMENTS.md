# R-John: Accessibility Requirements (Comprobables)

## Visual
- [ ] Text scaling 100%-200% (slider, 10% increments)
- [ ] High contrast mode (black/white/yellow palette)
- [ ] Colorblind mode (3 presets: deuteranopia, protanopia, tritanopia)
- [ ] Screen reader compatible (ARIA labels, alt text, focus indicators)

## Cognitive
- [ ] Clear choice descriptions (stat effects shown: ±Rep, ±Lust, ±Risk)
- [ ] Choice review (last 5 choices accessible anytime)
- [ ] No timed sequences (optional auto-advance 5-30s)
- [ ] Content warnings (before Chapter 6: scandal, crisis, mental health)

## Motor
- [ ] Full keyboard navigation (Enter, Space, Arrows, Ctrl+S, Ctrl+L, Ctrl+P)
- [ ] Click-only mode (toggle in Settings)
- [ ] Adjustable hold durations (100ms-2000ms slider)

## Audio
- [ ] Subtitles always on (cannot be turned off)
- [ ] Speaker identification (bold name before dialogue)
- [ ] Visual indicators for audio cues (stat bars animate)
- [ ] Volume controls (Music, SFX, Voice - three sliders 0-100%)

## Gameplay
- [ ] Remappable controls (key bindings menu)
- [ ] No rapid inputs required (all actions single press)
- [ ] Adjustable game speed (text scroll 50%-200%)
- [ ] Difficulty separation (Story/Standard/Hardcore modes)

## Save System
- [ ] Frequent saving (auto-save end of chapter, manual anytime)
- [ ] Reasonable retry (load from any save, no permadeath)
- [ ] Save migration (backward compatible, version number in file)

## Testing
- [ ] 10+ testers with disabilities (2 visual, 2 colorblind, 2 motor, 2 cognitive, 2 control)
- [ ] Automated testing (axe-core, WAVE, Lighthouse, Pa11y)
- [ ] WCAG 2.1 Level AA compliant
- [ ] 100% completion by all testers, 0 critical barriers, 8/10+ satisfaction

**Todos los requisitos son comprobables y medibles.**
