# R-John: UX & Accessibility Specification

**Única fuente de verdad para UX y accesibilidad**

## Requisitos (Comprobables)

### Visual
- Text scaling 100%-200%
- High contrast mode
- Colorblind mode (3 presets)
- Screen reader compatible

### Cognitivo
- Clear choice descriptions
- Choice review (last 5)
- No timed sequences
- Content warnings

### Motor
- Full keyboard navigation
- Click-only mode
- Adjustable hold durations

### Contenido
- Mature content toggle
- Mental health warnings
- Skip/recap functionality

## Testing
- 10 testers con discapacidades reales
- WCAG 2.1 Level AA target
- Section 508 compliant

## Checklist Pre-Launch
- [ ] Text scaling funciona
- [ ] High contrast legible
- [ ] Colorblind distinguishable
- [ ] Keyboard 100%
- [ ] Screen reader compatible
- [ ] Content warnings
